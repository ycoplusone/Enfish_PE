### MODBUS 프로토콜을 설명하시오 
#### 스마트 팩토리 통신 환경이 시리얼 기반 modbus에서 이더넷 기반 modbus TCP, Profinet으로 전환되는 추세.

**1. 산업용 장치 연결, MODBUS 프로토콜의 개요**
- 개념 : 기계장치의 자동화와 제어 위해 명령 모니터링을 수행하는 산업용 전자 장치 연결 시리얼 통신 프로토콜
- 특징
    - Master-Slave 기반 : Master는 요청, Slave는 응답
    - 산업용 통신 프로토콜 : 전자장치, 기계 제어 목적
    - 공개 무료 프로토콜 : 산업용 통신 방식 공개 문서
    - 간편 설치/유지 보수 : 단순 구조로 구현 및 유지보수 용이
    - 정보 조작 용이 : raw비트나 위드 단위 데이터 접근으로 유연한 처리

**2. MODBUS 프로토콜 구성요소 및 유형**
- 가) MODBUS 프로토콜 구성요소

|구분|구성요소|설명|
|:------|:-------------|:------|
|Header|Data Length|최소데이터 전송길이 주로 8비트 사용|
|Header|Parity bit|통신 데이터 검증 용도|
|Header|Stop bit|데이터의 종료 표시 비트 주로 1비트 사용|
|통신제어|Bitrate|초당 전달되는 비트수 주로 9600bps 사용|
|통신제어|Flow Control|버퍼 Full시 중단 요청 가능|

- 나) Modbus 프로토콜 유형

|구분|유형|설명|
|:------|:-------------|:------|
|Modbus종류|Modbus RTU|사업현장에서 사용하는 바이너리|
|Modbus종류|Modbus ASCII|ASCII문자 사용 텍스트형 전송방식|
|Modbus종류|Modbus TCP/IP|TCP/IP 계측에서 사용 Modbus RTU와 유사|
|시리얼통신방식|RS-232방식|1:1통신만 지원 전자파 노이즈로 데이터 변형 가능|
|시리얼통신방식|RS-422방식|전이중 통신 지원 최소 4개 선 필요하여 비용증가|
|시리얼통신방식|RS-485방식|주사용 방식 1:N 통신회선 연결 가능|

```MODBUS프로토콜은 대표적 SCADA시스템에서 제어장치와 설비간 데이터 교환용도로 널리 사용중```

**3. Modbus 를 적용한 SCADA 시스템 구조**

``` [감시시스템은 하나이다]
[산업설비] ←--명령/수집--→ [RTU] ←--Modbus 프로토콜--→ [감시시스템] --통계/감시-→ [관리조직]
                                                        ↕
[Sensor]  ←--명령/수집--→ [PLC] ←--Modbus 프로토콜--→ [감시시스템] --관리-→ [관리자]
```
- 스카다 시스템에서 Modbus외에 RP-570, 프로피버스, 코니텔 등 프로토콜 사용중
- 표준 프로토콜로 IEC 60870-5-101, 60870-5-104, IEC 61850, DNP3 등이 존재
